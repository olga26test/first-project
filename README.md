# GIT

## Навигация
```bash
pwd  #показать текущую директорию
cd  #сменить директорию
cd~  #сменить на дом. директорию
cd/  #перейти в корневую директорию
ls  #показать содержимое директории
ls -a  #показать скрытые папки ./
ls ..  #показать содержимое родительской директории
ls ~  #показать содержимое домашней директории
```
## Действия с файлами и папками

```bash
touch <название_файла.расширение>  #создать файл (можно неск-ко файлов через пробел)
mkdir <название_папки>  #создать папку
mkdir -p <папка/папка/название_папки>  #создать структуру папку в папке
cp <что_копируем> <куда_копируем>  #скопировать
mv <что_перемещаем> <куда-перемещаем>  #переместить
cat  #распечатать содержимое файла (только текстовые файлы)
rm <имя_файла>  #удалить файл
rmdir <имя_папки>  #удалить папку, если она пустая
rm -r <имя_папки>  #удалить папку со всеми файлами
```
## Инициализация репозитория, добавление файлов, коммит

```bash
git init  #инициализация репозитория
rm -rf .git  #"разгитить" папку (перед этим войти в папку с репозиторием)
git status  #проверить состояние репозитория
git add --all (или название_файла)  #добавить все файлы для отслеживания
git add <название_файла)>  #добавить файл для отслеживания
git commit -m 'Сообщение что исправлено'
```
## Генерация ключа (возможны ed25519, id_ecdsa.pub, id_dsa.pub, id_rsa.pub):

```bash
ls -la .ssh/  #проверка наличия ключа
ls -a ~/.ssh  #еще можно так проверить наличие ключа 
ssh-keygen -t ed25519 -C "электронная почта, к которой привязан ваш аккаунт на GitHub"  #генерация ключа
ssh-keygen -t rsa -b 4096 -C "электронная почта, к которой привязан ваш аккаунт на GitHub"  #еще один вариант генерации ключа
#место хранения ключей: домашний каталог по умолчанию - нажать Enter
#ввести кодовую фразу или нажать Enter (2 раза)
#в папке появятся 2 файла с расширением .pub (публичный) и без расширения (приватный)
clip < ~/.ssh/id_ed25519.pub  #скопировать содержимое ключа в буфер обмена
cat ~/.ssh/id_ed25519.pub  #скопировать содержимое ключа в буфер обмена (если clip не работает)
```

## Привязка локального репозитория к удаленному:

GitHub/страница репозитория/SSH/ - скопировать URL

консоль/перейти в каталог локального репозитория:

```bash
git remote add origin git@github.com:<ИМЯ_АККАУНТА>/<ИМЯ-ПРОЕКТА>.git  #привязка репозитория
#(вставить в консоль можно так: Ctrl+Shift+V или ПКМ: PASTE)
git remote -v  #убедиться, что репозитории связаны - появятся 2 строчки:
#origin    git@github.com:<ИМЯ_АККАУНТА>/<ИМЯ-ПРОЕКТА>.git (fetch)
#origin    git@github.com:<ИМЯ_АККАУНТА>/<ИМЯ-ПРОЕКТА>.git (push)
```
##  Загрузить на GitHub:

```bash
git push -u origin main  #или master (в первый раз)
git push  #в следующие разы можно без параметров
git log  #посомтреть лог гита
git log --oneline   #сокращенный лог
```
